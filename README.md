# MonkeyEmbryoidscRNA-seq
This repository includes code for processing and analyzing scRNA-seq of monkey embryoids generated by the study:
_**Modeling late gastrulation in stem-cell derived monkey embryo models**_

1.Cellranger_pipeline: The code script in Shell for cellranger pipeline which is executed on Linux system.

2.Data_processing_and_profiling: The code in R to perform QC and construct seurat object for downstream analysis.

3.Integration: The codes in R to perform integration analysis between the scRNA-seq data from monkey embryoids, in vivo CS8-9 monkey embryos, in vitro cultured monkey embryos and human PCW3(CS10) embryo.
